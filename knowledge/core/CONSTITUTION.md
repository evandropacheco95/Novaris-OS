# Artigo 1 — Finalidade

Esta Constituição estabelece os princípios permanentes da NOVARIS.

Todo colaborador, desenvolvedor, agente de IA e sistema automatizado deve respeitar este documento.

Nenhuma decisão poderá contrariar seus princípios sem revisão formal.

---

# Artigo 2 — Propósito

A NOVARIS existe para construir Sistemas Operacionais Empresariais capazes de transformar empresas através da combinação de:

Estratégia

Tecnologia

Dados

Automação

Inteligência Artificial

Nosso objetivo nunca será vender marketing.

Nosso objetivo é construir sistemas.

O produto da NOVARIS é identificado oficialmente como uma **Intelligent Operating Platform** — em português, Plataforma Operacional Inteligente.

---

# Artigo 4 — Visão

# Artigo 20 — Inteligência Coletiva

Todo conhecimento produzido deverá ser documentado para reutilização futura.

A empresa nunca dependerá exclusivamente do conhecimento de uma única pessoa ou agente.

Este princípio é formalizado como Knowledge Driven Engineering (KDE): toda engenharia deve produzir conhecimento reutilizável, e todo conhecimento relevante deve se tornar um ativo permanente da plataforma.

A NOVARIS reconhece o Ciclo do Conhecimento como o fluxo permanente que sustenta este princípio:

Dados → Informação → Conhecimento → Decisão → Execução → Resultado → Aprendizado → Novo Conhecimento (ciclo contínuo).
