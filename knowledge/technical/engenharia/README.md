# Engenharia — Conhecimento Institucional

## Objetivo

Preservar o conhecimento prático de como a NOVARIS constrói software no dia a dia — convenções que emergiram do uso real, armadilhas já identificadas, e o "porquê" por trás de padrões de código que não estão óbvios só de ler o padrão.

## Escopo

Convenções informais consolidadas, armadilhas conhecidas em ferramentas/bibliotecas usadas, decisões de processo (fluxo de PR, ritmo de releases).

## Responsabilidades

Mantido por quem escreve e revisa código no dia a dia.
