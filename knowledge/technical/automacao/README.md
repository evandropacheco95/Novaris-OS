# Automação — Conhecimento Institucional

## Objetivo

Preservar o conhecimento prático sobre como os workflows de automação da NOVARIS (n8n) se comportam em produção — limitações encontradas, integrações frágeis, e o que já quebrou uma vez.

## Escopo

Comportamento observado de workflows n8n sob carga real, integrações externas que se mostraram instáveis, padrões de retry que funcionaram ou não.

## Responsabilidades

Mantido por quem constrói e opera as automações.
