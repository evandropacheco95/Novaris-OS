# Decisões — Backend

## Objetivo

Registrar decisões de implementação de backend que não têm peso arquitetural suficiente para um ADR, mas afetam como serviços futuros devem ser construídos.

## Escopo

Convenções de schema não cobertas formalmente, escolhas de como estruturar uma Edge Function, decisões de índice/performance pontuais.

## Responsabilidades

Registrado por quem implementa a decisão de backend.
