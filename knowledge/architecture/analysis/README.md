# NOVARIS — Architecture Analysis

## Purpose

Investigações de evidência documental, executadas antes de qualquer Design Freeze ou decisão vinculante — a etapa de "Discovery" aplicada a questões de arquitetura de negócio, não apenas a domínios individuais. Cada documento aqui usa o mesmo método de 6 critérios/3 perguntas já aplicado às Discoveries de `Permission` (EPIC-004) e `Event Bus` (EPIC-006), sem autoridade para inventar ou resolver — apenas reunir e classificar evidência.

## Scope

Cobre:
- Investigação de existência/evidência de um domínio ou conceito em disputa (`CRM_DOMAIN_DISCOVERY.md`).

Não cobre:
- A decisão formal resultante de uma investigação — isso é `../decisions/` (ex.: `CRM_DOMAIN_DISCOVERY.md` → `ADR-0011-crm-domain-position.md`).
- Princípios de processo — isso é `../governance/`.

Uma análise nesta pasta nunca é, por si, vinculante — ela alimenta uma decisão em `../decisions/` ou permanece como "bloqueado" até nova evidência existir. Nenhuma análise aqui altera `DOMAIN_MODEL.md`, código ou ADR; o princípio "Evidence Before Freeze" (`../governance/ARCHITECTURE_GOVERNANCE.md`) nomeia exatamente esta pasta como seu precedente de origem.
