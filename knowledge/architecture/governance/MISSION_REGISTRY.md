# Mission Registry

Versão: 1.0.0

Status: 🟢 Oficial — registro append-only, obrigatório para toda missão futura

Missão: DOC-0002 (Handbook Externo Reconciliation & Documentation Integrity) — ver § "Retroatividade" abaixo.

## Objetivo

Registrar **todo** Mission-ID já usado no repositório NOVARIS, para que qualquer nova missão o consulte **antes** de escolher um número — substituindo a busca textual manual (`grep`) que já falhou 4 vezes nesta engenharia (`ENG-0020`, `ENG-0022`, duplo uso de `ENG-0022.1`, `EPIC-001`). Este documento formaliza o princípio "Mission ID Uniqueness", já citado em `ARCHITECTURE_GOVERNANCE.md` desde `ENG-0000.5`, mas nunca antes mecanicamente verificável.

## Regra de Uso

**Antes de abrir qualquer nova missão**: consultar a tabela abaixo, confirmar que o ID pretendido não está listado, executar a missão, e **adicionar uma linha nova a este documento** como parte do próprio relatório final da missão — nunca depois, nunca por outra missão. Números nunca são reutilizados, mesmo que a missão original tenha sido revogada ou superada (mesmo princípio de `adr/README.md § Convenção`).
