# Playbooks

> ➡️ **Redirecionado** ([ADR-0008](../adr/ADR-0008-foundation-freeze.md), Missão ENG-0000.5, Foundation Freeze): `engineering/playbooks/` é a localização oficial única de playbooks da NOVARIS a partir de agora — técnicos e de negócio. Esta pasta nunca teve conteúdo real (`🚧 Nenhum playbook criado ainda`), então nada foi perdido na consolidação. Novos playbooks, inclusive de negócio/produto, devem ser criados em [engineering/playbooks/](../engineering/playbooks/README.md).

## Histórico (antes da consolidação)

Esta pasta existia para reunir procedimentos passo a passo replicáveis de **negócio e produto** (ex.: "como lançar uma feature", "como integrar um novo cliente enterprise"), como contraparte de negócio a `engineering/playbooks/` (procedimentos técnicos). Nunca chegou a ter um playbook real. Migrou de `knowledge/playbooks/` para a raiz por [ADR-0002](../adr/ADR-0002-reestruturar-arvore-do-repositorio.md).

## Relação com Outros Módulos
