# NOVARIS

**NOVARIS** é uma plataforma SaaS full-stack construída sobre Next.js, Supabase/PostgreSQL e integrações nativas de IA (OpenAI, Claude, MCP), com automações via n8n e deploy contínuo na Vercel.

Este repositório é a fonte única de verdade (*single source of truth*) do projeto: arquitetura, produto, engenharia, operações e negócio. Antes de qualquer implementação, toda decisão relevante deve estar documentada em [docs/](docs/README.md).

> 📖 **Documentos oficiais**: [knowledge/core/NOVARIS_OS.md](knowledge/core/NOVARIS_OS.md) é a fonte oficial da visão da plataforma (v1.0.0, Oficial); [knowledge/core/CONSTITUTION.md](knowledge/core/CONSTITUTION.md) é a Constituição única e vinculante (23 Artigos, [ADR-0008](adr/ADR-0008-foundation-freeze.md)); [NEF/README.md](NEF/README.md) é a referência estrutural canônica de engenharia (v1.0.0, Oficial — 10 pilares, papéis, modelo de planejamento e roadmap mestre); [knowledge/engineering/NOVARIS_ENGINEERING_HANDBOOK.md](knowledge/engineering/NOVARIS_ENGINEERING_HANDBOOK.md) é o guia canônico de onboarding em leitura linear ([ADR-0009](adr/ADR-0009-engineering-entry-point-authority.md)); [NES/README.md](NES/README.md) é histórico (redirecionado para os dois acima). Toda decisão arquitetural deve respeitar esses documentos. **A Foundation está congelada** ([FOUNDATION_STATUS.md](FOUNDATION_STATUS.md)) — mudanças estruturais exigem ADR. Governança geral do repositório, incluindo a Matriz de Autoridade Documental por assunto, em [PROJECT_RULES.md](PROJECT_RULES.md).

## Por Onde Começar

1. Leia [docs/00-visao-geral/README.md](docs/00-visao-geral/README.md) para entender o propósito do produto.
2. Leia [architecture/README.md](architecture/README.md) para entender as decisões técnicas.
3. Leia [NEF/README.md](NEF/README.md) para entender o framework de engenharia (papéis, modelo de planejamento, pilares) antes de abrir qualquer Mission.
4. Leia [engineering/primeiros-passos.md](engineering/primeiros-passos.md) para configurar o ambiente de desenvolvimento, e [engineering/decision-tree.md](engineering/decision-tree.md) antes de implementar qualquer coisa.
5. `pnpm install` para instalar dependências do monorepo; `cp .env.example .env.local` e preencha; `docker compose up -d` sobe o Postgres local; `pnpm dev` roda tudo via Turborepo.
6. Consulte [CONTRIBUTING.md](CONTRIBUTING.md) antes de abrir um Pull Request.
