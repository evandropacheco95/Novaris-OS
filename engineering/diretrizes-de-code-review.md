# Diretrizes de Code Review

## Objetivo do Code Review

Garantir corretude, consistência com os [padrões de código](padroes-de-codigo.md) e disseminação de conhecimento — não é um gate burocrático.

## O que Revisar

- Corretude funcional
- Aderência à arquitetura documentada em [architecture/](../architecture/README.md)
- Cobertura de testes — ver [estrategia-de-testes.md](estrategia-de-testes.md)
- Segurança — ver [docs/09-seguranca](../docs/09-seguranca/README.md)
- Documentação atualizada junto com o código
