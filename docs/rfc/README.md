# RFC — Request for Comments

## Objetivo

Propostas técnicas anteriores a um ADR formal — espaço para discutir uma direção antes dela virar decisão vinculante em [adr/](../../adr/README.md).

## Escopo

Ideias e propostas em discussão. Diferente de um ADR: uma RFC não é vinculante, pode ser rejeitada sem virar registro histórico permanente, e pode gerar zero, um ou mais ADRs.

## Convenção

`NNNN-titulo-curto-da-proposta.md`, numeração sequencial própria (não compartilhada com `adr/`).

## Relação com Outros Módulos

- [adr/](../../adr/README.md) — destino formal de uma RFC aprovada
- [.command-center/CHANGE_REQUEST.md](../../.command-center/CHANGE_REQUEST.md) — para mudança em algo que já existe; RFC é para proposta nova ainda não decidida
