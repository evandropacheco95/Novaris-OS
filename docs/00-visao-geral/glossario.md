# Glossário

Termos e siglas usados de forma consistente em toda a documentação do NOVARIS. Mantenha em ordem alfabética.

| Termo | Definição |
|---|---|
| ADR | *Architecture Decision Record* — registro formal de uma decisão de arquitetura, ver [adr/](../../adr/README.md) |
| Edge Function | Função serverless executada próxima ao usuário, hospedada no Supabase |
| MCP | *Model Context Protocol* — protocolo padrão para conectar modelos de IA a ferramentas e fontes de dados externas |
| RLS | *Row Level Security* — mecanismo do PostgreSQL/Supabase para controle de acesso a nível de linha |
| SaaS | *Software as a Service* — modelo de entrega de software via assinatura |
| Tenant | Cliente/organização isolado logicamente dentro da plataforma multi-tenant |
