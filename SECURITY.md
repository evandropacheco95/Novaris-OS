# Política de Segurança

## Escopo

Este documento define como vulnerabilidades de segurança devem ser reportadas e tratadas no NOVARIS. Para a documentação completa de arquitetura de segurança, veja [docs/09-seguranca/README.md](docs/09-seguranca/README.md).

## Reportando uma Vulnerabilidade

- **Não** abra uma issue pública para vulnerabilidades de segurança.
- Reporte de forma privada aos mantenedores do projeto (canal a ser definido).
- Inclua passos de reprodução, impacto estimado e, se possível, uma sugestão de correção.
