# Pilar 8 — Templates

## Objetivo

Reunir os formulários/templates reutilizáveis da engenharia NOVARIS.

## Responsabilidades

Apontar para os templates já existentes — este pilar não cria template novo nem duplica os existentes.

## Regras

- Templates de gestão de engenharia (missão, sprint, bug, feature request, change request, plano de implementação, code review, release): [.command-center/](../../.command-center/README.md) — 11 templates.
- Templates de arquitetura de serviço (service, module, api, adr, event, repository, usecase): [knowledge/engineering/templates/](../../knowledge/engineering/templates/README.md) — 7 templates.
- Template de ADR: [adr/TEMPLATE.md](../../adr/TEMPLATE.md).
- Template de especificação de feature: [specs/SPEC_TEMPLATE.md](../../specs/SPEC_TEMPLATE.md) (⚠️ sobreposição não resolvida com `specifications/`, já registrada).
- Template de especificação de objeto: [knowledge/core/OBJECT_SPECIFICATION_TEMPLATE.md](../../knowledge/core/OBJECT_SPECIFICATION_TEMPLATE.md).

## Exemplos

Para abrir o EPIC-001, a Ordem de Missão correspondente segue [.command-center/MISSION_TEMPLATE.md](../../.command-center/MISSION_TEMPLATE.md); o serviço em si segue [knowledge/engineering/templates/service-template.md](../../knowledge/engineering/templates/service-template.md).
